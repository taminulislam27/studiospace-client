# StudioSpace

Peer-to-peer creative workspace and production studio sharing platform.

**Live site:** _add your Vercel URL here_

## Features

- Discover and filter photo studios, sound stages, podcast rooms, music suites and art workshops
- Host your own studio listing with full CRUD (add, view, update, delete)
- Book studio slots with double-booking prevention
- Email/password and Google login with BetterAuth
- JWT in HTTPOnly cookies protecting server-side mutations
- Light and dark theme toggle

## Tech stack

Next.js (App Router), DaisyUI, BetterAuth (MongoDB adapter), react-hot-toast, Swiper, Express.js, MongoDB.

## Local setup

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in the values
3. Start the server repo (`studiospace-server`) on port 5000
4. `npm run dev` and open http://localhost:3000
